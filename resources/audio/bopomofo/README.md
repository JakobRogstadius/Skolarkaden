The original stereo WAV recordings (`F1.WAV`–`F37.WAV`) were converted to mono
48 kbit/s MP3s and renamed by symbol Unicode code point (`3105.mp3`–`3129.mp3`).
Their spoken content is unchanged. They cover ㄅ through ㄩ in Unicode order.
Rebuild with `python3 dev/build-bopomofo-audio.py PATH_TO_SOURCE_ZIP`.
